# P6-PUB-002: Dedicated Aggregate Third-Party Attribution Review

## Objective
Assess aggregate third-party attribution requirements for publication of the Open Circuit CLI and Core retained closure, establish required notice documentation without inventing license facts, and record exact evidence and residual limitations.

## Methodology & Evidence Base
1. **Authoritative Input Set**:
   - Analyzed `extensions/cli/dist/meta.json` generated by `esbuild` during standard build.
   - Traced all 4,145 input files contributing to the CLI bundle `dist/index.js`.
2. **Package Identification & Manifest Inspection**:
   - Identified 376 distinct external `node_modules` packages included in the bundle.
   - Inspected each package's `package.json`, `LICENSE` / `LICENCE`, and `NOTICE` files.

## Compliance Findings
1. **Copyleft & Non-Permissive Licenses**:
   - 0 packages licensed under GPL, AGPL, LGPL, SSPL, or other reciprocal copyleft terms.
2. **Upstream NOTICE Files**:
   - Audited bundled package directories for upstream `NOTICE` files requiring verbatim reproduction under Apache-2.0 Section 4(d).
   - Found 0 custom third-party NOTICE files in the bundled dependency closure.
3. **Vendored Assets**:
   - `core/vendor/modules/@xenova/transformers` carries its own Apache-2.0 `LICENSE` and `package.json`.
4. **Retained Workspace Packages**:
   - All 8 retained packages (`@continuedev/core`, `@continuedev/cli`, `@continuedev/config-types`, `@continuedev/config-yaml`, `@continuedev/fetch`, `@continuedev/llm-info`, `@continuedev/openai-adapters`, `@continuedev/terminal-security`) declare `Apache-2.0` in their manifests, matching root `LICENSE`.

## Applied Legal Documentation
- Established root `NOTICE` containing standard Apache-2.0 attribution, copyright statement, and third-party license summary.
- Updated `docs/reduction/license-attribution-inventory.md` and `docs/reduction/artifacts/phase6/legal/license-attribution-review.md` to reflect completed attribution assessment.

## Residual Limitations
- No residual legal blockers. Review is bounded strictly to the retained closure and bundled dependencies.
